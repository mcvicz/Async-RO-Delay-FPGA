## 3. Kluczowe argumenty techniczne (jak dopytuje)

| Pytanie | Odpowiedź |
|---|---|
| Czemu CARRY4? | Twarde makra, dedykowany fast carry routing, ~50ps/stopień, deterministyczne. Trudniej Vivado wyciąć. |
| Czemu pętla nie znika? | dont_touch + keep + jawne prymitywy + ALLOW_COMBINATORIAL_LOOPS. Walka z optymalizatorem. |
| Czemu prescaler? | Ring setki MHz, licznik 100MHz mierzy max 50MHz (Nyquist). Dzielimy /256 w domenie async. |
| Czemu mock sym nie SDF? | XSim zawiesza się na combinational loop (event queue explodes). Znany limit narzędzia. |
| Sync vs async? | Sync: stabilny, jitter ~12ppm, brak czułości termicznej. Async: jitter ~4000ppm, silna f(T) → to czujnik/TRNG. |
